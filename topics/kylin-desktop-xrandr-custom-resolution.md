# 银河麒麟桌面 V10 SP1：使用 xrandr 添加自定义分辨率

## 场景与状态

- 系统：银河麒麟桌面操作系统 V10 SP1（`Kylin Linux Desktop V10 SP1`，`ID_LIKE=debian`，`KYLIN_RELEASE_ID=2503`）。
- 现象：图形界面「显示」设置中可选 `1360×768`（截图所示当前选择，`74.99 Hz`）、`1440×900`、`1600×1200` 等，但缺少所需的 `1600×900`。
- 处理：尝试在 X11 会话中使用 `xrandr` 创建并挂载新的显示模式。
- 验证状态：用户反馈所给命令**可以执行**；未记录实际 `xrandr` 输出、显示端口名称、切换后的效果或重启后保留情况。因此不要把本案例表述为“永久生效已验证”。

## 操作步骤

先确认图形会话类型及显示输出名称：

```bash
echo "$XDG_SESSION_TYPE"
xrandr
```

此方法面向 **X11（`x11`）**；若是 Wayland，不能直接照搬。根据 `xrandr` 输出中标为 `connected` 的显示输出，确定实际端口（例如 `HDMI-1`、`DP-1` 或 `eDP-1`）。

生成 1600×900、60 Hz 的 modeline：

```bash
cvt 1600 900 60
```

常见输出中的模型参数：

```text
Modeline "1600x900_60.00" 118.25 1600 1696 1856 2112 900 903 908 934 -hsync +vsync
```

将 `cvt` 生成的参数用于创建模式：

```bash
xrandr --newmode "1600x900_60.00" 118.25 1600 1696 1856 2112 900 903 908 934 -hsync +vsync
```

以下以 `HDMI-1` 为**占位示例**；实际运行时必须替换为第一步查到的输出名：

```bash
xrandr --addmode HDMI-1 "1600x900_60.00"
xrandr --output HDMI-1 --mode "1600x900_60.00"
```

切换后执行 `xrandr` 并检查显示效果，确认 `1600×900` 已启用。添加成功也可能因显卡驱动、显示器或链路限制而无法切换。

## 常见问题与约束

- `xrandr: command not found`：缺少 `xrandr` 软件包。
- `BadMatch`、`Configure crtc failed`：显卡驱动、输出接口或显示模式可能不接受此参数，需根据完整错误及 `xrandr` 输出排查。
- `Can't open display`：当前环境无法访问对应的 X 图形会话。
- `--newmode` / `--addmode` 属于会话内配置，**不能默认认为重启后永久有效**。确认手动切换稳定后，可另行配置登录自启动脚本（如 `~/.config/autostart/`），且需要避免在 Wayland 下误执行。
- 不要猜测屏幕端口名称，也不要仅因系统桌面显示有其他更高分辨率，就保证自定义模式一定被物理显示器接受。

## 后续复用时需获取的信息

```bash
echo "$XDG_SESSION_TYPE"
xrandr
```

根据实际输出名定制命令；如用户希望永久生效，再结合桌面环境和登录会话配置持久化。
