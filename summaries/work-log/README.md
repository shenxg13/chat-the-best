# 工作日志

按月份归档、按实际工作日期记录，用于回顾工作与整理周报、月报。

## 维护约定

- 用户提供哪天做了什么，再整理到对应日期；不从历史聊天或项目动态推断已完成的工作。
- 月度文件命名为 `YYYY-MM.md`，与本文件同目录；收到首条实际记录时再创建对应月份文件。
- 每天使用 `## YYYY-MM-DD` 标题，按日期升序排列；同一天的补充合并到当天，避免重复。
- 每项工作简要写明事项、实际行动及已明确的结果；未提供的结果、工时、原因不补写。计划、排查中、已完成须按用户原意区分。
- 明确日期优先；“今天”“昨天”按消息发送时用户的本地日期换算，日期不明确时先确认。
- 支持补记和更正历史日期的记录，保留无关原有内容。
- 仓库公开，仅记录脱敏工作摘要，不写生产 IP、账号、密码、Token、内部敏感信息或未经确认可公开的附件。
- 日志不代替项目任务管理，不因记录日志自动创建 Issue。
