# chat-the-best

这是一个用于和 ChatGPT / Codex 长期协作的通用上下文仓库。

它主要保存跨会话仍然有价值的内容，例如：

- 项目背景与阶段性总结
- 已确认的技术结论和决策
- 环境、架构和长期约束
- 后续新会话需要快速恢复的上下文

## 基本原则

- **需要推进到完成的任务**：放到对应项目仓库的 GitHub Issue 中追踪。
- **总结、背景、知识和决策记录**：直接维护为本仓库中的 Markdown 文档，不必创建 Issue。
- 新会话开始时，优先阅读 [`START-HERE.md`](./START-HERE.md)。
- 内容以简洁、可复用、便于后续会话快速恢复上下文为目标，不追求完整保存聊天记录。

## 使用方式

这个仓库可以作为不同 ChatGPT / Codex 会话之间的共享长期上下文层。

当一次讨论产生了值得长期保留的新结论时，可以把结论整理后提交到这里；具体开发任务仍由实际项目仓库的 Issue、PR 和代码来承载。
